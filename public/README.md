# Public Directory

This directory contains the built assets that are served by the FastAPI backend.

## 📁 Directory Structure

```
public/
├── index.html           # Main entry point for the Vue.js SPA
├── js/                  # Built JavaScript files (Vite output)
├── css/                 # Built CSS files (Vite output)
├── cache/               # Temporary data cache
├── results/             # Generated reports and data
└── README.md            # This file
```

## 🎯 Purpose

The `public/` directory serves as the **build output** for the Vue.js frontend application. It contains:

- **Built Assets**: JavaScript and CSS files generated by Vite
- **Entry Point**: `index.html` that loads the Vue.js application
- **Generated Content**: Reports, cache data, and other dynamic content

## 🔧 Build Process

1. **Development**: Vite dev server serves from `client/` directory
2. **Production**: Vite builds to `public/` directory
3. **Serving**: FastAPI serves static files from `public/`

## 📋 Guidelines

1. **Don't Edit Manually**: Files in `public/` are generated automatically
2. **Build Output Only**: Only contains built assets, not source code
3. **Version Control**: Generated files should be in `.gitignore`
4. **Clean Builds**: Run `npm run clean` to clear build artifacts

## 🚀 Development Workflow

```bash
# Development (serves from client/)
npm run dev

# Build for production (outputs to public/)
npm run build

# Clean build artifacts
npm run clean
```

## 📝 Notes

- The `index.html` file is the entry point for the Vue.js SPA
- All routing is handled client-side by Vue Router
- Static assets (icons, images) are served from `assets/` directory
- Generated reports are stored in `results/` subdirectory
